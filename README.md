# Pantry2Pack

Pantry2Pack is a Progressive Web App that connects people who need food assistance with a partner pantry and volunteer drivers who deliver the prepared packages. It overcomes transportation barriers by replacing in-person pickup lines with digital profiles, customizable wishlists, and automated route batching for direct doorstep delivery.

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Language:** JavaScript
